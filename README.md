# Job Tracker

Job Tracker is a personal job search management app built to help you stay organized throughout the entire application process. It keeps your opportunities, interview dates, follow-ups, and status changes in one place so you always know what needs attention next.

## Purpose

Track every role you apply to, see where each opportunity stands, and manage upcoming tasks from a single, focused workspace.

## Key Features

- **Dashboard** - View all applications in a searchable, filterable card grid. Summary analytics show total applications, pending interviews, offers received, and rejection rate at a glance.
- **Detail Panel** - Open any application in a slide-in panel to quickly update its status, add interview dates, or remove scheduled interviews without leaving the dashboard.
- **Kanban Board** - Move applications through each stage with a drag-and-drop board organized by status: Applied, Interview, Technical Test, Offer, and Rejected.
- **Calendar** - See scheduled interviews on a monthly calendar, with interviews displayed directly inside each day. Select a date to review full interview details.
- **Activity History** - Automatically log status changes and updates, creating a timeline for each application.
- **Smart Nudges** - Surface applications that may need follow-up, such as roles with no update after seven days or interviews that have gone three or more days without a response.

## Authentication and Storage

Job Tracker uses email and password authentication to protect each account. Application data is stored in Supabase, allowing your job search information to sync across devices while remaining private to your account.
